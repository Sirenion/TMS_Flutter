#Петрень Дмитрий Олегович
Заканчивал Минский Радиотехнический колледж по специальности "Программируемые мобильные системы" (2015-2019), там же получил знания по работе с сайтами, базами данных и мобильными приложениями (HTML,CSS,SQL,Java,Android,PHP). С 2019 работал преимущественно на фрилансе, занимался разработкой сайтов, мобильных приложений и API. Имеется высшее образование полученное в БГУИР по специальности "Инженер по инфокоммуникациям" (2019-2022). С 2022 по 2025 работал в РУП Белтелеком, занимался разработкой кроссплатформенных мобильных приложений на Flutter и модулей для Drupal на PHP. Несмотря на работу с Flutter почти в 3 года, при поиске нового места работы, всплыло огромное количество пробелов в знаниях, как теоретических, так и практических, для заполнения которых и был выбран данный курс.
